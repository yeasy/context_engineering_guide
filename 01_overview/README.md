# 第一章 上下文工程概述

大语言模型已经从实验室走向广泛应用。将模型用于复杂的实际场景时，一个关键问题随之出现：**如何让模型获得正确的信息，以产生可靠的输出？** 这正是上下文工程要解决的核心问题。

本章介绍上下文工程这一 AI 应用开发中的新兴学科的定义、起源与价值，以及它与传统提示词工程的区别，为后续各章奠定基础。
